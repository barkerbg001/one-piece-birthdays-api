One Piece Birthdays

A static JSON API of One Piece character birthdays. No key, no rate limit. Just fetch a file.

    Endpoints

    PathReturns
    v1/dates/MM-DD.jsonCharacters born on that day. All 366 days exist, including 02-29.
    v1/months/MM.jsonEvery day in that month.
    v1/all.jsonThe whole calendar.
    v1/characters.jsonEvery character with their birthday(s).
    v1/index.jsonCounts and endpoint list.

    Example

    GET v1/dates/05-05.json

    There is no today endpoint because the site is static. Work out today's MM-DD in your own timezone and fetch that file.
