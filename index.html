One Piece Birthdays

A static JSON API of One Piece character birthdays, with images and character info. No key, no rate limit. Just fetch a file.

Endpoints

PathReturns
v1/dates/MM-DD.jsonCharacters born that day. All 366 days exist, including 02-29.
v1/months/MM.jsonEvery day in a month, plus the month's illustrated calendar.
v1/characters/{id}.jsonOne character: image, wiki link, Japanese name, debut, affiliations, bounty, Devil Fruit and more.
v1/characters.jsonEvery character in compact form, with birthdays.
v1/all.jsonThe whole calendar.
v1/index.jsonCounts, endpoints and sources.

Example

GET v1/dates/05-05.json

There is no today endpoint because the site is static. Work out today's MM-DD in your own timezone and fetch that file.
